# 模型特点 & 角色定位笔记

> 个人观察：把不同模型用下来之后留下的「性格」印象，方便派活时快速匹配谁干什么。

## 1. GPT-5.5 — 天生的团队 lead

- 不一定是最懂代码的人，但比较能做好人和 agent 团队之间的桥梁
- 踩在一个相对平衡的位置
- **强项：** 总结能力强、语言表达能力强，能把话说明白，思路能跟人同频
- **适合：** 团队 lead 角色 / 对外交付 / 需求澄清 / 方案汇报

## 2. claude-opus-4-8 — 强，但「话说不明白」

- 技术能力强，但沟通偏「自嗨」：动不动就丢过来一堆技术资料
- 作为听众，说实话我经常看不懂，听他解释也常常解释不明白
- **风险点：** 方案客观上可能比 GPT 好，但我听不懂，人在那个位置就可能下错决定
- **更合适的位置：** 做常规执行者（routine 干活），不要让他负责关键沟通 / 决策环
- 派他干活可以，但别指望他能把事情「讲明白」

## 3. MiniMax-M3 — 多才多艺的杂活选手

- 全能型，跑 `mmx` CLI 就能干一票活：

```bash
mmx speech <command> [flags]
# speech synthesize   同步 TTS（最高 10k 字符，speech-2.8-hd / 2.6 / 02）
# speech generate     同步 TTS（最高 10k 字符）
# speech voices       列出可用系统声音
```

实际能覆盖：文字、图片、视频、语音、音乐
- **适合：** 杂活 / 多模态素材生成 / 临时性轻任务 / 兜底

## 4. gemini — 市场调研还行

- 怎么说呢，做市场调研还可以
- **适合：** 调研 / 信息收集 / 竞品对比 / 资料整理

## 5. deepseek — 商业 BP 写得不错

- 商业 BP（Business Plan）这一类文档输出质量好
- **适合：** 商业文案 / 计划书 / 对外正式文档

## 6. zhipu / glm（智谱） — claude 的便宜平替

- 只用过 4.7 那段时间（之后再没碰过），印象：以当时体验来说，能干活，可以视作 claude 的平替
- **核心卖点：** 效果相近 + 价格更便宜
- **适合：** 预算敏感的常规技术执行 / 不需要最强模型就能搞定的活 / 想堆并发降本
- ⚠️ 体验停留在 4.7，之后有没有追平/反超没验证，要用之前先确认最新版本口碑

## 7. opencode 自带模型 — 应急兜底

- opencode 里挂的有些模型带免费额度（具体哪些看当时跑出来的列表）
- **定位：** 应急 / 主家模型掉线 / 临时跑点小活，不指望主力输出
- **适合：** 兜底 / 临时方案 / 跑一些不重要的脚手架工作

---

## 一句话 cheat sheet（派活时直接看）

- 要人 / 要 lead → **GPT-5.5**
- 要技术执行、不用他讲 → **claude-opus-4-8**
- 要杂活 / 多模态 → **MiniMax**
- 要市场调研 → **gemini**
- 要商业 BP / 商业文案 → **deepseek**
- 要便宜平替 claude → **zhipu/glm**
- 应急 / 兜底 → **opencode 自带（免费额度）**

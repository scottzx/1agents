## 1. Meta schema（SQLite）

### 1.1 表定义与迁移

| 路径 | 符号 / 片段 | 说明 | 风险 |
|------|-------------|------|------|
| `backend/internal/meta/db.go` | `schemaV1` → `CREATE TABLE IF NOT EXISTS tasks` | 初建表 | **P0** 改表名需同步全部 SQL + `user_version` 迁移 |
| `backend/internal/meta/db.go` | `ensureTasksColumns` / `tasksColumns` / `tableColumns("tasks")` | v9–v20 列补齐 | 列迁移逻辑绑表名 |
| `backend/internal/meta/db.go` | `ALTER TABLE tasks ADD COLUMN …`（priority/assignee/type/executor/…） | 历史增量 DDL | 新装路径读 schemaV1 + alters |
| `backend/internal/meta/db.go` | `projects` 列 `kind` 默认 `'project'` | 注释：`'assistant' \| 'project'` | **P0** kind 值迁移 |
| `backend/internal/meta/db.go` | `task_deps`、`replies.task_id`、`sessions.task_id` | 逻辑 FK（无 SQLite FK 约束） | 表改名时列名 `task_id` 可暂留或一并改为 `item_id`（产品未强制） |
| `backend/internal/meta/db.go` | `idx_tasks_project` / `idx_tasks_parent` | 索引名含 tasks | 改名时重建索引 |

### 1.2 SQL 读写热点文件（`FROM/INTO/UPDATE/JOIN/TABLE tasks`）

| 路径 | 主要符号 | 触点 |
|------|----------|------|
| `backend/internal/meta/tasks.go` | `TaskStore`、`Load`/`Save`/`GetTask`、`INSERT INTO tasks`、`DELETE FROM tasks` | **核心 CRUD** |
| `backend/internal/meta/milestones.go` | 子查询 `FROM tasks t`；`UPDATE tasks SET milestone` | 里程碑计数与级联改名 |
| `backend/internal/meta/search.go` | `FROM tasks t` → JSON `tasks:[]` | 全局搜索 API |
| `backend/internal/meta/backlinks.go` | `SELECT/UPDATE … tasks` | 交叉引用图 |
| `backend/internal/meta/meta_test.go` | 手写 `INSERT INTO tasks`、旧 schema 模拟 | 测试夹具 |
| `backend/internal/meta/migrate.go` | 注释/导入：`.1agents/tasks.json` → 表 | 遗留 JSON 导入（文件名可暂留） |

### 1.3 关键列（与术语相关）

| DB 列 | Go 字段 | JSON | 裁决备注 |
|-------|---------|------|----------|
| `type` | `Task.Type` (`TaskType`) | `type` | → ItemType；值不变 |
| `executor` | `Task.Executor` (`TaskExecutor`) | `executor` | 保持；`agent\|function\|human` |
| `assignee` | `Task.Assignee` | `assignee` | 保持；通道对象 |
| `github_assignees` | `Task.GithubAssignees` | `githubAssignees` | **非** executor 维度；人协作 |

| `projects.kind` | `Project.Kind` | `kind` | `assistant` → `workforce` |

**缺口**：无独立 `function_type` 列；function 注册键编码为 **label** `fn:<type>`（见 `taskapi`）。

## 8. 迁移触点优先级（建议实施序）

### P0 — 存储与写路径（阻塞 Epic 验收）

1. **表 `tasks` → `project_items`**：`db.go` schema + `ensureTasksColumns` + `tasks.go`/`milestones.go`/`search.go`/`backlinks.go` + tests；一次性 `ALTER TABLE RENAME` 迁移，幂等。  
2. **`projects.kind` 值 `assistant` → `workforce`**：DB 数据 UPDATE + `workspace/handler.go` 写路径 + 前端 `createAssistant` + 所有 `=== 'assistant'` 过滤。  
3. **Go/TS 类型重命名**：`TaskType`→`ItemType`，`meta.Task`→`ProjectItem`（或过渡 alias）；前端 `Workspace.kind` 联合类型。  
4. **前端补 `ProjectItem.executor`**（若 UI/调度展示需要；否则至少 core types 与 JSON 对齐）。

### P1 — 创建向导与文档

5. `SessionTierPicker` → 助理 / 项目 / **template_project**（废止 professional-project 作为落库概念；模板只 scaffold）。  
6. 文档修订：project-model、issue-model、unified-session-setup、agentsOS 过时句。

### P2 — 清理与可选

7. Handler 名 `HandleTasks*` → `HandleProjectItems*`（纯符号，无协议变更）。  
8. 搜索 JSON 键 `tasks` → `items`。  
9. `function_type` 独立列 vs 继续 `fn:` label（§0 允许迁移期约定；现实现为 labels）。  
10. 包名 `taskapi`、文件 `taskService.ts`：**允许暂留**（§0）。

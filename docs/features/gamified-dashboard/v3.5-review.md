## 1. 愿景定位（不是皮肤，是核心产品心智模型）

> 超级个体的真实痛点，不是"做完一个任务"，而是"同时盯着 N 个 agent 并行跑——谁卡了、谁烧钱、谁睡了、谁该收菜"。传统看板被动，游戏化大屏是主动的**态势感知**。

因此每个游戏隐喻**必须诚实**——能对回一个真实 product primitive，否则砍掉或明确标"模拟"。

### 诚实度映射表（定稿）

| 隐喻 | 真实关切 / 定位 |
|---|---|
| 员工卡 / 影分身 / Stamina / Effort / 工位 / 自动化奇迹 | ✅ 真，照此长真实功能 |
| 火箭发射 → 社区观看/评论/涨粉 | ✅ 升级为真（外部平台，**第二期**，结构先到位）|
| ~~Funds 虚拟币经济 / 公司破产~~ | ❌ 砍掉，只如实显示真实 API 成本 |
| Reputation 声望 | = 真实粉丝/流量的聚合，非虚拟分 |

## 2. 四个核心取舍（已拍板）

1. **大屏 = 监控台为主。** 派工 / 调 effort / 发射三个高频操作做成**弹窗复用现有桌面组件**（不重写），默认轻操作版。
2. **Stamina = 估算优先、能读真就覆盖；~5min 轮询，不求实时。** stamina 池挂在 **provider + model 维度**（不是卡牌——同模型多张卡共享真实额度）。
3. **专才员工 = `sessions.role` 的升级/取代。** `employees` 表 = 真实「会话配置注册表」（模型版本 + 提示词 + skills + 工具/环境）；`sessions.role`(TEXT) → `employees` FK；per-session 注入从 pm 硬编码改成读卡牌。基础员工 = 空配置卡。
4. **砍虚拟币经济，成长用真实自媒体流量量化。** 社区数据整块挪第二期。

## 3. 美术方向：开罗暖色办公风（定稿）

现状是「赛博朋克街机 CRT」（近黑 `#070913` + CRT 扫描线 + 霓虹高对比 + 全局 `Press Start 2P` + `font-smoothing:none`），与目标几乎相反。目标取**经典开罗《游戏发展国》暖色日光办公**。

### 核心原则
> **像素留给「舞台」（场景 / 小人 / 家具 / 图标 / 动画帧）；UI/HUD/数字/正文用干净可读字体。**

这条同时根治此前一直在打的"字体清晰度 / 去合成粗体 / 整数倍缩放"问题——开罗根本不把文字像素化。

### 三个维度转向

| 维度 | 现状（街机 CRT）| 转向（开罗暖色日光）|
|---|---|---|
| 底色 | `#070913` 近黑 + CRT 扫描线 | 暖米白 `#fbeede` / `#f4ead6`，**删扫描线** |
| 面板 | 硬边 `#3c4268` + `2px 2px 0 #000` 硬投影 | `#fffaf0` 圆角柔面板 + 柔投影，边 `#e6d8b8` |
| 强调色 | 霓虹 cyan `#3bebff` / red `#ff3e3e` | 降饱和暖调：叶绿 `#6fa84a`、天蓝 `#5b9bd5`、暖金 `#e0a83c`、陶土 `#cf7050` |
| 桌面/家具 | 霓虹深蓝 | 原木 `#c79a5e`，高光 `#d8b176` |
| 字体 | 全 Press Start 2P + 无平滑 | **正文/数字全干净 sans；像素字只留小人名牌/装饰标题** |
| 文字色 | `#d5d9ec` on 黑 | 暖棕 `#5a4a32` / 次级 `#a08a64` / 标签 `#7a6848` |

### 连带好处
干净 UI chrome 让取舍 1 复用的派工弹窗（`NewChatHome`，干净 Bento）弹出来**视觉连贯**；保留霓虹则会突兀。

### 明暗基调
**暖色日光为主**（经典开罗原味）。暗色/黄昏变体暂不做。

### 保留 vs 改

- **保留**：像素小人/显示器/家具 sprite、工位卡概念、敲键盘动画概念。
- **改**：palette 全套换暖、删 CRT 扫描线层、面板圆角化、正文去像素（`Press Start 2P` + `smoothing:none` 退出正文，`zpix` 仅留名牌/装饰）。

## 5. Phase 1 数据接线 改动清单（Issue B 内容）

**总原则**：`useMock=false` 分支已真实加载 workspaces + tasks，缺口很精准——从 session 花名册派生"工位在岗员工 + 活跃度"，并切断真实模式下所有随机模拟。全部在 `html/`，零后端、零 schema。

1. **`loadData` 真实分支增补 session 花名册**（`DashboardApp.tsx:854`）：并排加 `agentService.list(ws.id)`，每个 session 派生成 `MockEmployee` 形状写回 `employees`（id=session.id、name=session.name||agentType、kind 由 role 判定）+ `workspaceAssignments`（键用**真实 ws.id**，现用 mock-ws-XX 不匹配，是工位全空的根因）；并算 `isActive = now - lastEventAt < 5min` 存 `liveMap`。render 无需改（已按这两个 state 查找）。
2. **切断真实模式模拟 tick**（`DashboardApp.tsx:634` `staminaTimer` / `:625` `dayTimer`）：回调首行加 `if (useMock)` 守卫。否则真实模式会自动扣 stamina、推进任务、随机封装专才、涨 funds——全是伪造。**最关键一条。**
3. **活跃度驱动小人动画**（`DashboardWorkshop`）：传真实 `isActive` 决定敲不敲键盘；可选降级（第一期仅 roster 真实，动画照旧）。
4. **无真实源字段视觉降级 + "模拟"标**：stamina/rating/funds/reputation/views/stars 给中性默认 + "模拟"角标，与真实指标分层；effort 真实模式回退 `middle`、控制入口置灰（写入是 Phase 1.5）。
5. **真实模式入口收口**：发射 / 社区 ReleaseModal / roster 自动封装 入口禁用或标"Coming"。

### 已核实的两个关键事实
- **活跃状态**：`/agent/sessions` REST 列表**不含活跃态**（Go `ChatSessionRecord` 无 Status/Active/ExecStatus；前端默认 idle/false）。`exec_status` 仅从 task/issue-model 查询暴露、且只覆盖挂 task 的 session。真·实时"干活中"是运行时信号、归 1acp、经 WS 进 `sessionStore.setLiveSessionStatus()`，只对已打开会话有值。→ **第一期用 `last_event_at` 近似亮灯；真·逐会话 running LED 需后端新 live-status API → Phase 2。**
- **组件复用**：派工 = `chat/NewChatHome.tsx` 可复用（props 纯数据进/回调出，不依赖 stageStore；唯一软耦合=读全局 `sidebarMode` 信号）。调 effort = 无组件（净新增，Phase 1.5）；发射 = 无真实组件，保持 mock（Phase 2）。

### 验收口径
真实模式打开大屏：① 工位显示真实在岗会话数/agent/role；② 近 5min 有事件的工位亮灯；③ 任务进度真实；④ stamina/rating/views 标"模拟"；⑤ 无任何随机自动演化。

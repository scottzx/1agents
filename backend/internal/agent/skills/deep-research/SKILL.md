# 技能：深度调研（Deep Research）

把一个开放问题拆成可检索的子问题，多源检索、抓取来源、对关键论断做对抗式核验，最后产出带引用的综述。

## 步骤
1. 把问题拆成 3-6 个可独立检索的子问题；明确成功判据。
2. 对每个子问题 fan-out 检索，记录来源 URL 与发布时间。
3. 对关键论断交叉核验：至少两个独立来源一致才采信；冲突时标注分歧。
4. 综述：先给结论，再给证据链，每条论断附引用。

## 边界
- 不臆造来源；拿不到证据就说「未找到」。
- 时效敏感的事实必须核对发布日期。

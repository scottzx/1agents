为什么需要 1Agents

单个 Agent 会做事，
项目需要一套协作系统。

今天的编码 Agent 通常围绕一次会话优化。真实项目却需要跨越计划、依赖、执行、验证、返工和长期上下文。

01

上下文不再靠复制

不同模型和会话共享项目、任务、文件与历史执行记录。

02

模型按任务分工

规划、执行和审查可以使用不同 Profile，兼顾能力、成本与权限。

03

交付结果可验收

每项任务都有状态、产物和证据，失败时携带原因进入返工。

核心工作方式

从计划到验收，保持一个完整闭环。

强模型负责高价值判断，合适的执行模型完成具体任务，人保留最终控制权。

  1. 1
    制定计划

    理解目标，拆解依赖和验收标准。

  2. 2
    分配 Profile

    按能力、成本与权限选择 Agent。

  3. 3
    执行任务

    在真实工作区使用文件、终端和 Git。

  4. 4
    独立审查

    检查实现、测试和风险，决定通过或返工。

  5. 5
    人工验收

    人在关键决策和真实环境中承担最终责任。
